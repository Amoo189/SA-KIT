درباره SA-CB

SA-Chemical Balancer ابزاری قدرتمند برای موازنه معادلات شیمیایی است که توسط صالح عمو توسعه یافته است.

این برنامه با استفاده از الگوریتم‌های پیشرفته ماتریسی، ضرایب استوکیومتری مناسب را برای معادلات شیمیایی پیدا می‌کند و نتایج را نمایش می‌دهد.

راهنمای استفاده
  • معادله را در کادر وارد کنید
  • از علامت = یا -> برای جدا کردن مواد واکنش‌دهنده و محصول استفاده کنید
  • از + برای جدا کردن مواد در هر طرف استفاده کنید
  • مثال: H2 + O2 = H2O
  • می‌توانید از نمونه‌های آماده استفاده کنید
  • نتیجه موازنه شده با ضرایب مناسب نمایش داده می‌شود
